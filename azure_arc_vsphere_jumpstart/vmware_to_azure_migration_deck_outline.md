# VMware to Azure Migration Deck Outline

This outline backs the generated PowerPoint deck in the same folder.

## Purpose

Create one presentation that works for:
- Business leaders evaluating urgency, risk, ROI, and investment direction.
- Technical decision makers planning discovery, landing zones, migration waves, and hybrid operations.

## Slide Flow

1. Title
- VMware to Azure Migration
- Executive and technical decision deck built from the Microsoft eBook and Microsoft Learn guidance.

2. How to use this deck
- Business leaders section
- Technical decision makers section
- Shared decisions and handoff to migration planning

3. Executive summary
- Three main paths: Azure VMware Solution, Azure VMs/PaaS, Azure Arc-enabled VMware vSphere
- Core value points: speed, agility, security, cost optimization

4. Section divider: Business leaders

5. Why act now
- Aging infrastructure and security pressure
- AI readiness and cloud scale requirements
- Licensing, resiliency, and operating model benefits on Azure

6. Choose the right migration lane
- Azure VMware Solution
- Azure VMs plus Azure PaaS
- Azure Arc-enabled VMware vSphere
- Azure Virtual Desktop / Horizon Cloud on Azure

7. Section divider: Technical decision makers

8. Technical migration workflow
- Discover
- Dependency mapping
- Business case
- Readiness assessment
- Migration and validation

9. Target-state architecture decisions
- Keep VMware operating symmetry where appropriate
- Modernize selected workloads to native Azure platforms
- Use mixed placement where it improves outcomes

10. Azure VMware Solution landing zone essentials
- Subscription, region, quota, CIDR, network gateway, NSX-T segments
- Platform landing zone and application landing zone responsibilities

11. Wave planning and tooling
- Pilot
- Factory wave 1
- Factory wave 2+
- Optimize

12. Hybrid operations with Azure Arc-enabled VMware vSphere
- Azure control plane over vSphere resources
- RBAC, governance, VM lifecycle operations, phased migration support

13. VDI and end-user compute options
- Azure Virtual Desktop
- VMware Horizon Cloud on Azure

14. Economics and optimization levers
- Azure Hybrid Benefit
- Reserved capacity
- Extended Security Updates in Azure
- Right-sizing from Azure Migrate assessments

15. Common risks and mitigation patterns
- Dependency blind spots
- Network overlap and late landing-zone design
- Placement indecision across target platforms

16. Recommended 90-day action plan
- Days 1-30 discovery and segmentation
- Days 31-60 assessment, landing zone, and pilot planning
- Days 61-90 pilot execution and scale-out approval

17. Sources
- eBook plus Microsoft Learn guidance
